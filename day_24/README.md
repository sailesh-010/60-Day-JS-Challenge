## Day 24: creating new Elements with js.

This is my **Day 24** of javascript for cybersecurity journey. Today I focused on manipulating the DOM using JavaScript.

## Overview
    -document.createElement allows us to creating new elements with Js.
    -prepend allows us to add elements to the beginning of the parent element.
    -appendChild allows us to add elements to the end of the parent element.
    -remove allows us to remove elements from the DOM.
        


## What We Learned
    -I learned about the different methods to manipulate the DOM using JavaScript.
    -I learned how to use the `prepend()` and `appendChild()` methods to add elements to the DOM.
    -I learned how to use the `remove()` method to remove elements from the DOM.
