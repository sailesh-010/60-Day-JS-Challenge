# 📅 Day 33: `.then()` and `.catch()` in JavaScript

This is my **Day 33** of the **JavaScript for Cybersecurity** journey.  
Today, I learned how to handle **Promises** using `.then()` and `.catch()`.

---

## 🔍 Overview

- **Promises** handle asynchronous operations
- `.then()` runs when a promise is **successful**
- `.catch()` runs when a promise **fails**
- Helps avoid **callback hell**

---

## 📘 What I Learned

- `.then()` handles resolved results
- `.catch()` handles errors
- Makes async code cleaner and easier to debug
- Commonly used in:
  - API requests
  - Authentication
  - Token validation

---

## 🔐 Cybersecurity Insight

- Proper promise handling prevents:
  - Unhandled errors
  - Broken authentication flows
- Clean async code improves **security and reliability**
