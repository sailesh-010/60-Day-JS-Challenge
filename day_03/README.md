This is my Day 3 of learning JavaScript.
In this file, I am learning about comparison operators in JavaScript.
The code demonstrates the difference between loose equality (==) and strict equality (===), as well as their respective inequality operators (!= and !==).

    "==" this operator checks only for equality of values.
    "===" this operator checks for equality of both values and data types.

    "!=" this operator checks only for inequality of values.
    "!==" this operator checks for inequality of both values and data types.
