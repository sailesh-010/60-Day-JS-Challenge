📅 **Day 42: How to Use Packages in Node.js**
This is my Day 42 of the **JavaScript for Cybersecurity** journey.

Today, I explored **how to install and use packages in Node.js**, how npm manages dependencies, and why packages are essential for building scalable and secure applications.

## 🔍 Overview

```
    -Packages are reusable modules published to npm
    -npm is the default package manager for Node.js
    -Packages help avoid writing repetitive code
    -Dependencies are stored in node_modules
    -packages are imported using require() or import
```

## 📘 What I Learned

```
    -npm init creates a package.json file
    -npm install downloads packages from npm registry
    -package.json tracks project dependencies
    -require() is used in CommonJS modules
    -import is used in ES modules
```

## 🔐 Cybersecurity Insight

```
    -Using trusted packages improves development security
    -Outdated packages can introduce vulnerabilities
    -Unnecessary dependencies increase attack surface
    -Always review package reputation before installing
    -Regular updates help patch known security flaws
```
