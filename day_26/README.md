## Day 26: creating event listeners in JS.

This is my **Day 26** of javascript for cybersecurity journey. Today I focused on different types of event listeners in JS.

## Overview
    - "mouseover" event listener
        This listen when mouse is over the element.
    - "mouseLeave" event listener
        This listen when mouse is leave the element.
