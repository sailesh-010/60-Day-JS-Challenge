# Day 09: JavaScript Basics - Closures and Scope

## Overview
In this lesson, we will explore the concepts of closures and scope in JavaScript. Understanding these concepts is fundamental to writing effective and maintainable JavaScript code.

In closures create new counter(memory) for each function call.
In scope, each function has access to the variables in its parent scope.
