# 📅 Day 33: `try{}...catch{}` in JavaScript

This is my **Day 33** of the **JavaScript for Cybersecurity** journey.  
Today, I learned how to handle **Promises** using `try{}...catch{}`.

---

## 🔍 Overview

    - **Async/Await** is a modern and cleaner way to handle **Promises**.
    - Makes asynchronous code look and behave like synchronous code.
    - Improves **readability**, **error handling**, and **security logic flow**.
    - Widely used in:
        - API requests
        - Authentication systems
        - Secure data fetching
        - Log analysis tools


---

## 📘 What I Learned
    - `try{}` handles resolved results
    - `catch{}` handles errors
    - Makes async code cleaner and easier to debug
    - Commonly used in:
    - API requests
    - Authentication
    - Token validation


---

## 🔐 Cybersecurity Insight
    - Proper promise handling prevents:
        - Unhandled errors
        - Broken authentication flows
    - Clean async code improves **security and reliability**
