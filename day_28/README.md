## Day 28: creating event listeners in JS.

This is my **Day 28** of javascript for cybersecurity journey. Today I focused on different types of e.target in JS.

## Overview
   -e.target is a property of the event object (e) that refers to the element that triggered the event. In the context of the user list example, e.target would be the specific <span> element that was clicked.
   types of e.target:
    -e.ctrlKey: Returns true if the Ctrl key was pressed while the event occurred.
    -e.shiftKey: Returns true if the Shift key was pressed while the event occurred.
    -e.altKey: Returns true if the Alt key was pressed while the event occurred.
    -e.metaKey: Returns true if the Meta key (e.g., Command key on Mac, Windows key on Windows) was pressed while the event occurred.


## What We Learned
   - I learned how to use e.target to get the element that triggered the event.
   - I learned how to use e.target to check if a specific element was clicked.
