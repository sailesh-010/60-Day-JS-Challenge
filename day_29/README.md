## Day 29: creating event listeners in JS.

This is my **Day 29** of javascript for cybersecurity journey. Today I focused on different types of e.target in JS.

## Overview
    -Event bubbling is a mechanism in JS where an event triggered on a child element also bubbles up to its parent elements.
    -Event capturing is the opposite of event bubbling. Instead of bubbling up, the event starts at the root element and propagates down to the target element.

## What We Learned
   - How event bubbling works.
   - How event capturing works.
   - How to stop event propagation using e.stopPropagation().
