## Day 27: creating event listeners in JS.

This is my **Day 27** of javascript for cybersecurity journey. Today I focused on different types of form events in JS.

## Overview
   - "focus" event listener
        This listen when input field is focused.
   - "blur" event listener
        This listen when input field is blurred.
   - "change" event listener
        This listen when input field is changed.
   - "submit" event listener
        This listen when form is submitted.
